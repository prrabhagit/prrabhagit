I'm a computer engineering student focused on **backend systems** and **AI**, with a preference for building things from foundational technologies rather than leaning on high-level frameworks. I'd rather deeply understand one layer of the stack than skim ten.

-  Currently building full-stack and distributed systems projects in Java and Python

-  Believe in projects built well, over built shallow
